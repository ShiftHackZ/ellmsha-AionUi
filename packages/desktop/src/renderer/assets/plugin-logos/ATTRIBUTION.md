# Plugin logo sources

- `linear.svg`: Linear logomark from the official [Linear Brand Assets](https://linear.app/brand) download, `logo-light.svg`.
- `clockify.svg`: Clockify logomark from the official [CAKE.com Clockify brand assets](https://brand.cake.com/) download, `clockify_logo_mark_positive.svg`.

- `figma.svg`: Official full-color Figma icon from [figma/mcp-server-guide](https://github.com/figma/mcp-server-guide/blob/main/Figma%20Icon%20%28Full-color%29.svg), also linked from the [GitHub MCP registry entry](https://github.com/mcp/com.figma.mcp/mcp). The SVG viewport is cropped to remove surrounding whitespace; its paths and colors are unchanged. See [Figma Brand Usage Guidelines](https://www.figma.com/using-the-figma-brand/).

Linear and Clockify marks are bundled unchanged. All names and marks belong to their respective owners.
